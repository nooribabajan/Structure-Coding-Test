2. Imperial Academy Development Strategy

Imperial Academy کو reverse-engineering strategy کے تحت مرحلہ وار تیار کیا جائے گا۔

مرحلہ 1: Subject-specific features
مرحلہ 2: Class-level features
مرحلہ 3: Academy-level features

کچھ features subject-specific ہوں گے، کچھ class-specific اور کچھ Academy-wide۔ منظور شدہ architecture کو برقرار رکھا جائے گا اور غیر ضروری redesign سے گریز کیا جائے گا۔

3. Master Academic Content Development Workflow

ہر Chapter اور Topic میں academic development پہلے ہوگا اور HTML architecture میں placement اس کے بعد ہوگی۔

1. مکمل curriculum اور textbook teaching material جمع کرنا۔
2. تمام متعلقہ graphics، diagrams، illustrations اور visual learning material جمع کرنا۔
3. Core curriculum content کا کوئی حصہ omit نہ کرنا، حتیٰ کہ جزوی طور پر بھی نہیں۔
4. تمام material کو topic-wise organize کرنا۔
5. Learning sequence کو academic logic کے مطابق map اور paginate کرنا۔
6. ہر Topic کے لیے اس کے مزاج کے مطابق مناسب teaching method طے کرنا۔
7. مکمل academic organization کے بعد content کو approved HTML/Academy architecture میں رکھنا۔

4. Classes 7–12 — Universal Teaching Standard

Classes 7 سے 12 کے تمام Subjects کے لیے ہر Topic کو ایک مکمل Teaching Unit کے طور پر تیار کیا جائے گا۔

4.1 بین الاقوامی معیار کا تعارف

ہر Topic کا آغاز ایک مضبوط، واضح، دلچسپ اور بین الاقوامی معیار کے Introduction سے ہوگا۔

  • Topic کیا ہے؟
  • یہ کیوں اہم ہے؟
  • اس کا حقیقی زندگی یا broader subject سے کیا تعلق ہے؟
  • طالب علم کو یہ Topic کیوں سیکھنا چاہیے؟

4.2 بین الاقوامی معیار کا Lecture

ہر Topic کو اس کے academic nature کے مطابق بہترین teaching method سے پڑھایا جائے گا۔

ضرورت کے مطابق درج ذیل طریقے استعمال کیے جا سکتے ہیں:

Conceptual Explanation Step-by-Step Teaching Diagrams Examples Comparisons Processes Cause & Effect Scientific Reasoning Applications

4.3 Standards-Aligned Question & Answer

ہر Topic کے بعد Question & Answer section کو تین بنیادی standards کے مطابق تیار کیا جائے گا:

  1. International Standard
  2. Current relevant KP / local Curriculum & Examination Standard
  3. MDCAT Standard — جہاں applicable ہو
Assessment ہمیشہ طالب علم کی Class، Subject اور متعلقہ examination level کے مطابق ہوگا۔

9. Acode Testing Protocol

Chapter development کے بعد اسے Acode میں بار بار check کیا جائے گا۔

Testing Area Check
HTML Loading Page صحیح load ہو رہا ہے۔
Navigation Next / Previous اور تمام navigation controls درست کام کریں۔
Go To Required learning step/page پر صحیح لے جائے۔
Search Search functionality درست کام کرے۔
Visual Atlas Visual/diagram functionality درست کام کرے۔
Chapter Test Test صحیح open، operate اور result دے۔
Paths کوئی broken یا غلط path نہ ہو۔
Mobile Mobile screen پر layout اور interactions درست ہوں۔

14. What Must Not Be Bypassed

Academic content collection اور organization کو bypass نہیں کیا جائے گا۔
  • Core curriculum content omit نہیں ہوگا۔
  • Topic-wise organization skip نہیں ہوگی۔
  • Learning sequence mapping skip نہیں ہوگی۔
  • Topic-specific teaching approach skip نہیں ہوگی۔
  • Introduction skip نہیں ہوگا۔
  • International-standard lecture skip نہیں ہوگا۔
  • Standards-aligned Q&A skip نہیں ہوگا۔
